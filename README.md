# Talisman of Death

Fighting Fantasy gamebook adaptation using Godot 4 engine, developed in **C#**.

## 📖 Project Description

This project is a digital adaptation of the **"Talisman of Death"** Fighting Fantasy gamebook. The goal is to create an interactive adventure game for desktop, web, and mobile platforms.

## 🏗️ Technology Stack

- **Engine**: Godot 4.3+
- **Programming Language**: C# (.NET 6/7/8)
- **Solution Format**: .slnx (Microsoft XML-based)
- **Target Platforms**: Windows, Web, Android, iOS

## 📁 Project Structure

```
├── scenes/              # Godot scene files
├── scripts/             # C# source code
│   ├── Game/           # Main game logic
│   ├── UI/             # User interface
│   └── Data/           # Data structures
├── assets/             # Game assets (images, sounds)
└── docs/               # Documentation and book sources
```

## 📚 Fighting Fantasy Elements

- **Character Statistics**: Skill, Stamina, Luck
- **Dice-based Combat**: 2d6 + Skill mechanics
- **Branching Story**: 400+ numbered sections
- **Inventory System**: Gold, items, equipment

## 🌍 Localization Features

- **Multilingual Support**: English and Hungarian
- **Dynamic Language Switching**: In-game language switcher
- **Automatic Language Detection**: System locale-based defaults
- **Built-in Translation System**: Dictionary-based C# implementation
- **Complete UI Localization**: All interface elements translated
- **Reliable Loading**: No external file dependencies
